# 华园课表 0.3.0 设计

用户已确认 0.2.8 实机同步成功，并要求周一凌晨自动更新、及时提醒临时调课、优化 UI；确认额外白天每六小时检查。

## 行为
- 北京时间周一 00:15 + 每天 08:00/14:00/20:00。JobScheduler 持久化单次任务、有网络时执行，系统限制可能推迟；无精确闹钟权限、无服务器。
- 复用 WebView Cookie 会话；失效通知一次并在主页提示用户登录。网络失败保留旧数据并退避重试；关闭自动更新则取消任务。只在检测到变化时发课表通知。
- 同步代码从 Activity 提取为共享 SyncEngine / WdkbClient，前后台串行，延用成功的 transport。
- Python 保存前比较规范化的名称、教师、教室、星期、节次、周次；忽略时间戳、ID、顺序和格式变化。首次导入建立基线，不报全表调课；更换学期单独标识。记录最多 30 批变化，并与课表一起原子写入。
- 非普通 KBLB 记录单独保存可解释字段，变化提醒为特殊安排待核对；不臆测取消、考试的含义或放入正常网格。
- 保存教务返回的学期开始日期以自动计算当前周；旧数据缺日期时显示手动周次，不根据猜测计算。

## UI
本地 HTML/CSS/JS WebView 仅作离线课表 UI，不加载远程内容；通过枚举动作桥接原生同步/权限/文件选择。CAS 保持独立原生 WebView，永不暴露桥接接口给校方页面。
三页：课表（自动本周、周切换、网格/清晰列表、今天、课程详情、同步状态）；调整（新增/移除的前后安排和校方特殊记录）；设置（更新开关、检查频率、通知权限、导入导出、账号）。使用系统字体、48px主要按钮、蓝白低饱和课程配色。

## 验证边界
Java 离线时段算法与已有 transport 测试；Python 变化/重复/特殊安排/坏响应原文件不变测试；浏览器检查同一 HTML 资产的窄屏、宽屏、点击、无横向溢出及 XSS；Android 编译、lint、版本签名。没有真机后台执行证据时不声称验证了真实调度或通知到达。

## 追加确认
用户指定厦门校区，要求现实时间与实时课程。使用教务处现行公开作息、接口学期日期、北京时间；上课/下课边界、课间、跨日跨周和手动浏览与实时卡片隔离有回归测试。
